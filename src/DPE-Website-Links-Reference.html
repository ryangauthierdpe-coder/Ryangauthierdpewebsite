📋 DEPLOYMENT QUICK REFERENCE

Step 1: Deploy to Vercel

  1. Export code from Figma Make
  2. Sign up at vercel.com
  3. Create new project, upload code
  4. Add environment variables (Supabase URL & Anon Key)
  5. Click Deploy

Step 2: Connect Domain in Vercel

  1. Go to Project Settings → Domains
  2. Add: dperyan.com and www.dperyan.com
  3. Vercel will show DNS records

Step 3: Update GoDaddy DNS

  1. Log in to GoDaddy
  2. Go to DNS settings for dperyan.com
  3. Add A record: @ → 76.76.21.21
  4. Add CNAME: www → cname.vercel-dns.com

Step 4: Deploy Supabase Backend

From terminal/command prompt:

npm install -g supabase
supabase login
supabase link --project-ref [your-project-id]
supabase functions deploy make-server-e4d9f7d7

Step 5: Verify Email Domain (Resend)

  1. Go to resend.com/domains
  2. Click "Add Domain", enter: dperyan.com
  3. Add DNS records shown by Resend to GoDaddy
  4. Click "Verify" in Resend
